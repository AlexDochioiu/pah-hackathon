# Sound library licences

Every file here is CC0 1.0 (public domain dedication, https://creativecommons.org/publicdomain/zero/1.0/): free to
use, change and redistribute, no attribution required. We credit the authors anyway. Each file was trimmed,
made mono 48 kHz, loudness-normalised (sfx: loudest 400 ms at -16 LUFS; music: -20 LUFS integrated, limited at
-2 dBFS) and encoded as Opus in Ogg. The CC0 licence was checked on each source page on 2026-11-07.

Adding a sound: drop a CC0 (or otherwise redistributable) `name.ogg` into `sfx/` or `music/`, add a row here, and
a one-line description in `ABOUT` / `MUSIC_ABOUT` in `../sounds.py`; the prompt lists it automatically.
